### Hi, I'm Aurélien 👋

Random developer doing random stuff with random technology.

### What I build

- [**wirdigen**](https://github.com/Cerclique/wirdigen): generates Lua dissector plugins for Wireshark.
- [**waybar-gpui**](https://github.com/Cerclique/waybar-gpui): a Rust SDK for writing a GPUI panel and opening it as a popover from a Waybar module on Hyprland.
- [**caesium**](https://github.com/Cerclique/caesium): a colorized logger that prefixes each line with the time elapsed since start, built on `env_logger`.
- [**dotfiles**](https://github.com/Cerclique/dotfiles): personal dotfiles managed with GNU stow.
